# 🎓 Smart Student Management System

## 📖 Project Overview

A web-based Student Management System developed using PHP and MySQL. It helps manage student records, attendance, internal marks, rooms, and room allocations through admin and student dashboards.

## ✨ Features

- Admin registration and login
- Student registration and login
- Student management
- Attendance management
- Internal marks management
- Room management
- Room allocation
- Reports and profile management
- Secure logout

## 🛠️ Technologies Used

- HTML5
- CSS3
- PHP
- MySQL
- XAMPP
- phpMyAdmin

## 🚀 How to Run the Project

1. Install XAMPP.
2. Copy the project folder into `xampp/htdocs`.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Import `smart_student_management_system.sql`.
6. Open:

`http://localhost/Smart_Student_Management_System/`
